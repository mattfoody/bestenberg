AI-native visual editor on Gutenberg.

== Description ==

Bestenberg replaces the default Site Editor experience with a fast, opinionated, token-based visual editor. Everything is stored as native blocks, so your site keeps working without the plugin.

* Own editor: live canvas of the real page, structure tree, token-based settings, phone/tablet/desktop preview.
* Section library and components; header, footer and templates are editable too.
* Generate sections from a description or a screenshot with the AI provider connected in WordPress.
* WooCommerce: product, catalog, cart, checkout and order confirmation templates.
* Client mode: editors change text, images and links; designers decide what else.

== Installation ==

1. Upload and activate the plugin, then the Bestenberg theme.
2. Open Bestenberg in the admin menu. On an empty site, choose "Add demo pages".
3. Enable auto-updates for the plugin and theme.

== Frequently Asked Questions ==

= What happens if I deactivate Bestenberg? =

Content is stored as WordPress blocks. Text, images and buttons stay core blocks; Bestenberg's layout blocks need the plugin to render.

= Does it send data anywhere? =

Only when you use Generate (your description and optional screenshot go to the AI provider you connected) and when WordPress checks for Bestenberg updates (the update server; with your license key if you entered one).
